# 프로젝트 주제 선정

## 1. 후보

  1. 영상 분석 서비스

  2. AI-Ops 튜닝 & 이상 감지 시스템

  3. RAG 기반 지식 관리 마이크로서비스

## 2. 선정

  * RAG 기반 지식 관리 마이크로서비스

  * 선정 이유: 내가 실제고 겪었던 문제를 해결할 수 있고 AI API와 RAG를 가장 효율적으로 활용할 수 있는 프로젝트라 생각했기 때문

## 3. 현재 문제와 사용 대상

  * 개발을 하다 보면 각종 기술 문서를 참고해야 할 때가 많은데, 개발자가 단기간에 방대한 양의 기술 문서를 이해하고 활용하기는 쉽지 않음

  * 현재는 각종 생성형 AI를 활용하여 기술 문서 설명을 요청하고 코드를 생성하지만, 경험상 Hallucination이 나타나서 문제 해결이 오래 걸리거나 아예 수작업으로 해결한 경우도 있었음

  * ex. Java + Spring Framework를 이용해 개발을 하던 중 현재 사용되고 있는 Spring Boot 4.x를 인식하지 못하고 Spring Boot 3.x가 최신 버전이라고 인식. 패키지 의존성 버전도 최신 Java LTS인 Java 25보다 과거에 머물러 있음. (com.fasterxml.jackson.databind와 tools.jackson.databind 등)

## 4. 해결 방법

  * 생성형 AI의 Hallucination을 방지하고 보다 명확한 결과를 도출하기 위해 사용자가 요청한 기술 문서 내에서 검색 후 결과 도출
