# ingestion-worker 문서 업로드 중 발생한 문제

* 아직 프론트엔드 문서 업로드 기능을 구현하지 않은 상태였으므로, PowerShell 명령어를 이용해 문서를 업로드한 상태였다.

* 문서 내용 요약을 요청하자 HTTP 504 Gateway Timeout 응답 코드를 반환했다.

* 새 노트북 세션을 열어 같은 작업을 요청했을 때는 문서를 찾을 수 없다는 답변을 한 것으로 보아 문서는 정상적으로 업로드되었지만, 이후 과정에서 오류가 발생한 것으로 보인다.

# Trial 1
* 원인을 찾기 쉽지 않아 직접 Postgres Pod에 접속해보기로 하였다.

* POST /api/v1/sessions/.../chat 요청에서 504 응답이 확인된 것으로 보아 Nginx -> API Gateway -> Chat API 구간의 응답 지연일 가능성이 높다.

* Gemini API 재시도 횟수를 3회로 늘리고 Gemini 전체 타임아웃은 30초로 설정하였다.

* Nginx 타임아웃은 150초로 설정하였다.

## Trial 1 Result

* 새로운 문서를 생성했는데 요청 한도 초과 메시지가 표시되었다.

* API 사이트에서 확인한 결과 이는 사실이었다.

* 임시로 Gemini 버전을 일간 요청 한도가 고갈된 `gemini-3.8-flash`에서 당일 요청 전적이 없는 `gemini-3.6-flash`로 교체하였다.

* 로컬에서 업로드한 PDF 파일을 정상적으로 이해한 모습을 프론트엔드로 볼 수 있었다.
